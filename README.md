# Career Analytics & Skill Intelligence Platform

A data-driven career guidance system that analyzes resumes using Machine Learning and NLP techniques.

## Features

- Resume Parsing
- Skill Extraction
- Career Prediction
- Skill Gap Analysis
- Resume Quality Scoring
- Learning Recommendations
- User Authentication
- Analysis History
- PDF Report Generation

## Tech Stack

- Python
- Flask
- SQLite
- Scikit-Learn
- Pandas
- NLP
- HTML/CSS
- Bootstrap
- Render
